# Arena Inclusiva — Esporte Sem Limites ♿🏅

Projeto desenvolvido para o Curso Superior de Informática da **UNICID**.

## 🎯 Objetivo
Promover a inclusão social, acessibilidade, autonomia e saúde de pessoas com deficiência por meio do esporte adaptado.

## 🚀 Funcionalidades
- Sistema de Recomendação de Esportes por Inteligência/Compatibilidade.
- Barra de Acessibilidade Completa (Alto Contraste, Fontes, Leitor de Tela, Modo Escuro).
- Questionário de Perfil Multi-etapas Condicional.
- Catálogo e Detalhes de Esportes Paralímpicos.
- Persistência via `LocalStorage`.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Variáveis CSS, Flexbox, CSS Grid)
- JavaScript ES6+ (Sem dependências externas)
