# Arena Inclusiva — Esporte Sem Limites

Existem **duas formas** de rodar este projeto no seu VS Code (ambas incluídas nesta pasta):

### Opção 1: Mais Rápida (Sem precisar instalar nada!)
1. Abra o arquivo **`index.html`** no VS Code.
2. Clique com o botão direito sobre ele e selecione **"Open with Live Server"** (ou dê um duplo clique no `index.html` na sua pasta).
3. Ele já vem com React, Tailwind CSS e Lucide Icons integrados para abrir exatamente com o visual da primeira versão!

### Opção 2: Projeto React Completo (Vite)
1. Abra o terminal no VS Code (`Ctrl + '`).
2. Digite `npm install` e aperte Enter.
3. Depois digite `npm run dev` e abra o link exibido no navegador.
